An end-to-end data analytics project exploring customer demographics, purchasing patterns, subscription trends, and product performance across 3,900 e-commerce transaction records.

---

## 📋 Executive Summary
This project analyzes consumer behavior patterns to uncover revenue drivers and conversion bottlenecks. Using **Python** for Data Cleansing & Feature Engineering, **PostgreSQL** for business logic querying, and **Power BI** for visual reporting, the pipeline transforms raw transaction logs into strategic e-commerce insights.

### Key Metrics:
* **Total Customers Analyzed:** 3,900
* **Average Spend per Transaction:** $59.76
* **Average Product Rating:** 3.75 / 5.0
* **Subscription Conversion:** 27% Subscribed | 73% Non-Subscribed

## 🛠️ Data Pipeline & Methodology

```
┌─────────────────┐     ┌──────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│ Raw CSV Data    │ ──> │ Python / Pandas  │ ──> │ PostgreSQL DB    │ ──> │ Power BI        │
│ (3.9k records)  │     │ ETL & Engineering│     │ Complex Querying │     │ Visualization   │
└─────────────────┘     └──────────────────┘     └──────────────────┘     └─────────────────┘
```

1. **Data Cleaning & Preprocessing (`Python/Pandas`)**:
   * Resolved 37 missing values in `Review Rating` via category-wise median imputation.
   * Standardized column headers to lowercase SQL conventions.
   * Dropped redundant feature `promo_code_used` (100% duplicate of `discount_applied`).
   * Binned age metrics into 4 quartile-based segments (`Young Adult`, `Adult`, `Middle-aged`, `Senior`).
   * Mapped purchase frequencies into numerical days (`purchase_frequency_days`).

2. **Database Integration (`SQLAlchemy` & `PostgreSQL`)**:
   * Automatically loaded cleansed data into PostgreSQL DB `customer_behavior`.
   * Executed 10 analytical business queries (CTE segmentation, window functions, and aggregation logic).

3. **Dashboard & Visualization (`Power BI`)**:
   * Engineered interactive slicers for Subscription, Gender, Category, and Shipping Type.
   * Modeled sales volumes, age group revenue contributions, and subscription rates.

## ❓ Business Queries Answered (PostgreSQL)

| Query ID | Business Question Focus | SQL Techniques Used |
| :--- | :--- | :--- |
| **Q1** | Revenue generated by Male vs. Female customers | `SUM`, `GROUP BY` |
| **Q2** | Customers using discounts spending above average | Subqueries, Multi-condition `WHERE` |
| **Q3** | Top 5 products by average review rating | `AVG()`, Numeric Casting, `LIMIT` |
| **Q4** | Standard vs. Express Shipping purchase amount | Conditional Filtering, `AVG()` |
| **Q5** | Average spend & revenue: Subscribers vs. Non-subscribers | Multi-metric Aggregation |
| **Q6** | Top 5 products with highest discount rate | Conditional `CASE WHEN`, Percentage Math |
| **Q7** | Customer Segmentation (New, Returning, Loyal) | CTEs, `CASE` statements |
| **Q8** | Top 3 products within each category | Window Functions (`ROW_NUMBER() OVER`) |
| **Q9** | Subscription conversion rate among repeat buyers (>5 purchases) | Aggregation, Threshold Filtering |
| **Q10** | Revenue contribution by Age Group | Categorical Aggregation |

## 🚀 How to Run

1. **Clone Repository**:
   ```bash
   git clone https://github.com/your-username/customer-behavior-analysis.git
   cd customer-behavior-analysis
   ```
2. **Setup Python Environment & Dependencies**:
   ```bash
   pip install pandas psycopg2 sqlalchemy
   ```
3. **Execute ETL Notebook**: Run `notebooks/customer_behavior_etl.ipynb` to process data and push it to your local PostgreSQL server.
4. **Run SQL Queries**: Import `sql/business_queries.sql` into pgAdmin/PostgreSQL.
